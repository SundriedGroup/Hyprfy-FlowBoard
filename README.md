# Hyprfy Flowboard v0.9.8

Visible verification: `BUILD v0.9.8`.

## 0.9.8 — Ideas Library
- New **Ideas** space in the sidebar.
- Ideas are separate from Inbox.
- Capture: Title, Channel, Source/Link, Why I Like It.
- Channel colour coding applies to ideas too.
- Open an idea to edit it or open the original reference.
- **Turn into content** creates a new unscheduled content block in Inbox.
- The original inspiration stays saved in Ideas.
- No database migration required. Ideas use `flow_items` with `item_type = idea`.
